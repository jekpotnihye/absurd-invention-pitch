A make.fun entry for "One Sentence Absurd Invention Pitch" (`u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a`).

`main.ts` writes one sentence — an absurd invention pitch fixing a tiny everyday annoyance — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with no trailing newline.

Entry:

> The Butler Curtain is a shower curtain with tiny suction-cup hands that holds itself politely aside and bows whenever you step in, ending its shameful habit of clinging to wet strangers.

Run it with Node 22:

```sh
node main.ts
```
